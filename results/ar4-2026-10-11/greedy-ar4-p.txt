### 1. Prerequisites and Topology
Before the transaction occurs, the following conditions must be met:
*   **Topology:** Both GPUs (GPU A and GPU B) are connected to different downstream ports of the same PCIe Switch.
*   **Address Space:** GPU A has been assigned a Base Address Register (BAR) region in the system memory map that corresponds to GPU B’s memory. This is typically done by the BIOS/UEFI or the OS during initialization.
*   **IOMMU/VT-d:** If an IOMMU (Input-Output Memory Management Unit) is enabled, it must be configured to allow P2P traffic or to translate the addresses correctly. In many high-performance GPU clusters, IOMMU is often bypassed or configured in "passthrough" mode for P2P to reduce latency.
